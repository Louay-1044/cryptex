# Language
Language that should be generated by the blocks.

## GENERAL INFO
- Statements should end with semi-colons (;). Empty {} blocks cannot exist.
- Currencies are represented like string but only with singular '' quote marks, currencies are treatable like numbers with their value being the value in USD.
- Numbers are are real (floats).

## VARIABLES
Variables must first be declared with a type (number or currency), this can change if needed.
```
var *VAR_name* number;
var *VAR_name* currency;
```
In order to avoid conflicts generated variables should start with 'VAR_', and declared at the top.
Variables can be given values, increase, and decrase:
```
*VAR_name* := 0;
*VAR_name* += 1;
*VAR_name* -= 1;
```

## NUMERICAL EXPRESSIONS
These expressions return a number, and can be used within each other.
```
*number* + *number*;
*number* - *number*;
*number* / *number*;
*number* * *number*;
*number* // *number*;
*number* % *number*;
math.random(*number*,*number*);
```

## BOOLEAN EXPRESSIONS
These expressions return a true or false,
```
*number* > *number*;
*number* >= *number*;
*number* < *number*;
*number* <= *number*;
*number* == *number*;
*number* != *number*;
*boolean* and *boolean*;
*boolean* or *boolean*;
not *boolean*;
```

## FUNCTIONS
Functions must be declared with a name, and parameters (with a type).
Async functions can also be created these functions will execute in parallel with main thread, unless await is used before call.
In order to avoid conflicts functions should start with 'FUNC_'.
### Create Functions
```
fn *FUNC_function_name*(*LOCAL_1* number, *LOCAL_2* boolean) {
}
fn *FUNC_function_name*(*LOCAL_1* number, *LOCAL_2* currency) {
}
fn *FUNC_procedure_name*() {
}
async fn *FUNC_async_function_name*() {
}
```

### Call Functions
```
*FUNC_function_name*(*number*, *boolean*)
*FUNC_procedure_name*()
*FUNC_async_function_name*()
await *FUNC_async_function_name*()
```

## CONTROL FLOW
### Stop
Immediatly exit the program.
```
stop
```

### Waiting
Wait an amount of time in seconds.
```
time.wait(*number*)
```

### Loops
There are 4 basic loops: repeat at number of times, repeat while a conditon, while not a conditon, and forever.
```
repeat *number* {
}
while *boolean* {
}
while not *boolean* {
}
forever {
}
```
There is also the foreach loop, which iterates throught all currencies.
```
foreach *LOCAL_local_name* {
}
```

### Branching
```
if *boolean* {
}
if *boolean* {
} else {
}
```

## TRADE FLOW
Get the price of a currency a *number* of seconds ago, note: values less than 60 will return current price. As this is the minumum fidelity of the binance api.
There is no method for getting current price see top of document for explanation on why.
```
trade.get_price(*cryptocurrency*, *number*);
```
Returns which ever is higher/lower of the two currencies current value.
```
trade.get_highest(*cryptocurrency*, *cryptocurrency*);
trade.get_lowest(*cryptocurrency*, *cryptocurrency*);
```

Returns the user liquid balance.
```
user.get_balance();
```
Return the amount owned of a currency.
```
user.amount_owned(*cryptocurrency*);
```
Buying/selling a *number* of *currency*.
```
user.buy(*cryptocurrency*, *number*);
user.sell(*cryptocurrency*, *number*);
```
