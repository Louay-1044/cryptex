# Stories
These user stories should server as the minimum basis of the project for the demonstration.

## Trader #1 Story
* User creates a trader account
* User looks at the available currencies and buys one
* User looks at portfolio demonstrating change
* User creates a simple algorithm using builder that simply sells all currencies just brought
* User looks at portfolio again demonstrating change

## Organisation Manager Story
* User creates an organisation manager account
* User creates an organisation
* User invites trader #2 to organisation

## Trader #2 Story
* User logins into preprepared account
* User looks at organisation invite and accepts
* User looks at builder and starts their more complicated preprepared algorithm
* User then looks at organisation page

## Organisation Manger
* Switch back to organisation manager
* Look at the organisation page to verify it is the same as trader #2
